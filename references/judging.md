# 裁判尺

裁判是这套东西里最容易坏的一环。LLM 当裁判有三个被反复测出来的偏置
（《Justice or Prejudice? Quantifying Biases in LLM-as-a-Judge》, ICLR 2025；
MT-Bench 亦记录同类现象）：**位置偏置**（谁排在前面谁占便宜）、**冗长偏置**（长文得分高）、
**自我增强偏置**（偏袒与自己文风相近的一方）。下面每一条规矩都是为了压住其中一个。

---

## 〇、先记分项，再定比分

这是全篇最要紧的一条，来自 Kahneman / Lovallo / Sibony 的 mediating assessments：
**先独立评几个具体属性，再给整体结论**。反过来做（先有「谁赢了」的直觉，再倒着填理由）
就是 coherence bias —— 你一定会填得出来，而且填得很像那么回事。

所以每一回合按下面四维各打 0–2 分，**打完才决定比分**：

| 维度 | 问的问题 | 0 分 | 2 分 |
|---|---|---|---|
| **接招** | 有没有正面回应对方这一回合的要害？ | 绕开、答了别的 | 指名驳倒，或承认驳不倒并说明代价 |
| **新据** | 有没有带来对方没有的东西？ | 只是复述立场 | 新的事实、新的算法、新的类比 |
| **自洽** | 自己前后有没有打架？ | 自相矛盾 | 与前面回合严丝合缝 |
| **认账** | 该认的认了没有？ | 含糊过去 | 明确认下，并给出替代解释 |

写进账本：

```bash
python3 "$SK/scripts/arena.py" turn --dir ./juban --round 3 --speaker A \
  --text-file /tmp/r3a.txt --score "A:2,B:1" \
  --rubric "A:接2,据2,洽2,认1;B:接1,据1,洽2,认2" --pivot "若你能指出..." --blind
```

`check` 会核一件事：**四维合计更占优的一方，必须是多分的那一方**。对不上就报警。
这不是完美防伪，但它拦住最常见的一种作弊——先定胜负再编理由。

---

## 一、三分制怎么切

一回合通常 3 分，先判「有没有交锋」，再判「谁得分」：

| 情形 | 记分 | 判词 |
|---|---|---|
| 一方命中对方要害，对方回避或含糊 | 2:1 | 「A 打中了 X 这一处，B 没有接住」 |
| 一方全面压制，对方整段失去落点 | 2:0 | 「B 这一回合没有回答本回合的问题」 |
| 双方各中一处，各有代价 | 1:1 | 「A 得 X，B 得 Y，本回合势均」 |
| 一方攻击落空（打了一个对方没主张的点） | 2:1 判给防守方 | 「B 打的是稻草人，A 不必答」 |
| 一方承认被驳倒且给出替代解释 | 1:1 或 2:1 视替代质量 | 「B 认了 X，但换出 Y，仍然站得住」 |
| 一方承认被驳倒但无替代 | 2:0 | 「B 认输且无补救，本回合失守」 |

2:0 与 1:1 都是 2 分，不是记错。`scoring.allowed_totals` 缺省就放行 `[3, 2]`。

**不许为「有胜负」硬压分。** 1:1 是合法结果。一场全是 1:1 的局，说明命题不可证伪，
这是对局的结论，不是裁判的失败。

## 二、五条硬规矩

1. **判词必须引原文。** 「A 更有说服力」是废话。合格判词长这样：
   「A 答了『户存而口缩是丁口隐匿』这一处，B 的『人众』就没有落点了。」
   引不出原文，说明你没读懂，别判。

2. **只认被写下的话。** 发言里没说出口的意图、你替他补的论证，一律不算。

3. **限长。** 发言按 250–500 字记。超长不加分，超短的照样判——否则会奖励灌水。

4. **不奖励认输，但要记账。** 认输是有分量的动作（说明角色在真的听），
   认完必须给替代解释才算止损；认完就停的，本回合照样失守。
   一句话记牢：**认输可以，把认输演成让步不行**（concession is fine;
   surrender-dressed-as-concession is not）。

5. **多数票不是证据。** 三个裁判投 2:1 并不能证明谁对；同模型跑三遍更是演戏。
   要多个裁判，就用不同模型、不同上下文，并且**其中任何一个给出了具体反驳理由，
   都该被认真对待**，哪怕票数落后。

---

## 三、自报要害：给双方一个必须被驳倒的句子

每条发言末尾自报一句 `要害：`（写进账本是 `--pivot`）：

> 要害：我这套账的关键只在「户头不划」——你若能证明流民入籍时户头会跟着划走，
> 我这二十年的算法全塌。

三个作用，缺一不可：

- **逼角色收口。** 不给靶子的发言可以一直含糊，给了靶子就必须承担一句话的后果。
- **防裁判稻草人。** 裁判攻击的点如果是角色自报要害之外的东西，角色可以不接。
  裁判不许另立靶子（这一条同时保护角色）。
- **让认输可核。** 「被驳倒」不再是模糊判断，退化成「那一句被驳倒没有」。

参考做法（来自多方辩论框架的 steelman 约定）：**要害那半句由角色自己写，裁判只许原样引用**，
不许改写、不许替它「更准确」地重述。

未自报要害的回合，在 `duel` 局里 `check` 是**硬错误**（exit 2），不是提示——没有靶子，
「要害被击穿」这个终局就永远判不了；认输那一回合免（他已经认了）。
`roundtable` / `camp` 局暂时不查这一项（多人发言时靶子归属复杂），但裁判仍应逐条要求。

---

## 三·补、什么算「可判的认输」

认输能直接结掉一局，所以门槛必须比「认一个细节错」高得多。三种情况分开处理：

| 场上发生了什么 | 处理 |
|---|---|
| 认下对方**没打到的点**（让了一步，绕开了要害） | 不结局。只记认账分，判词写清「他让的是 X，不是要害」 |
| 认下**要害的一部分**，并给出替代解释 | 不结局。听上去像认输，其实是换了个说法继续站着 |
| 认下**自己自报的那一句**，且指出被驳在哪一处 | **结局**，`--concede`，对手胜 |

反过来，裁判宣布击穿（`--ko`）也有同样的门槛：**打到的必须是对方报过的靶子**。
`check` 会核对这一点——若被击穿的人从未自报要害，会提示「打的是稻草人」。

这条规矩的意义：没有它，「认输」会退化成一种修辞，赢的人赢在一句漂亮话上，而不是赢在一处驳倒。

## 四、防偏置的三个动作

- **盲判**：先拿到不带署名的发言判分，判完再归属，`turn` 记 `--blind`。
  这一条不是可选项，也**不是默认值**——CLI 不替你决定，漏传 `--blind` 就是署名判。
  匿名互评的实验一致显示，**评委只要看见角色名就会偏袒**。
  但 `--blind` 只是账本上的一个标记，**它本身不遮蔽署名**——真要盲读，先用
  `arena.py brief --dir <对局目录> [--round N] [--out 盲读.txt]` 导出匿名视图，
  它抹掉真名、自报要害、比分和含真名的标题，只留席位牌与正文；读匿名稿判完分，
  再回账本 `turn --blind` 记分归属。只有文书上的自觉、没有工具上的遮蔽，盲判就是一句空话。
  底线：每局至少一半回合盲判（满 4 回合后 `check` 会计数，不足一半是硬错误）；
  出现连续三回合同一方赢时，必须盲判复核。
- **去长比对**：把双方发言砍到同样长度再读一遍，若结论翻转，以砍短后的结论为准。
- **换序复核**：把发言顺序倒过来再判一次。

出现「钟摆式交替」（A 赢 B 赢 A 赢 B 赢）时必须做——十回合里胜负严格交替，
通常不是水平相等，而是裁判在按轮次配平。

---

## 五、收敛警报：这一场是不是已经不出东西了

论道最常见的慢性死亡不是吵起来，是**双方开始互相恭维**：你夸我这一手漂亮，
我说你这一层我确实没想到，然后各让一步，回合照记，比分照走，实录全是水。

判断标准：

- **最近四回合全是平手**（1:1 / 2:2）——这是真收敛，`check` 自动提示。
  注意：交替出现的 2:1 **不算**收敛，那是两人咬得紧，不是互相让步。
- 一方连续三回合 2:0 —— 已经不是辩论，是单向输出，该提前收局（`check` 提示）。
- 八回合以上没有一次 2:0 —— 要么真势均，要么裁判没敢给分，`check` 会提一句。

触发后不许装看不见，必须做一件事：**在判词里点名「这一回合谁都没被驳到，为什么」**，
或者换一个更硬的命题。软绵绵地判下去，比判错更伤这局。

反过来，研究上有一条值得记的结论（Inducing Disagreement in Multi-Agent LLM
Executive Teams, OpenReview 2026）：**温和的「请你唱反调」几乎不起作用，
真正能制造出真异议的只有一种配置——专门盯住「已经浮现的共识」去攻**。
所以真正的收敛，是指双方都开始同意某个具体结论；那时候该派的是「魔鬼辩手」，
不是再打一回合。

## 六、事实纪律（`historical` / `truthseeking` 局必须执行）

- 引一句「某某说过」，裁判要能指到出处。指不到的，本回合该方扣到 0 分，并在实录里标注。
- **不许替角色圆场。** 角色引错了就是引错了，实录里写「此处引文有误」，不要悄悄改成对的。
- 数字要对得上：户口、兵力、粮数、年代，凡出现具体数字，判前心算一遍。
- 「我记得」不算证据。角色说「史载」却不给篇名，视为无据。

这条是最容易被跳过、也最影响可信度的一条。实录一旦掺进编造的史实，整场的分量就没了。

### 六·补、证据标签（`--evidence`）

事实纪律光靠「裁判记得核」仍然会漏。所以每一条发言都能挂一个证据等级，出档时亮出来：

| 标签 | 含义 | 判分处理 |
|---|---|---|
| `[已核] verified` | 指得到出处 / 可运行命令 / 可引用数据 | 全额采信 |
| `[推理] reasoned` | 从已核事实推出来，链条可复核 | 采信，但标出推理链 |
| `[待核] to-verify` | 声称有据但当场没核 | 打折采信，裁决里写明待核 |
| `[存疑] speculative` | 无出处、或已被对方拆穿的硬圆 | 不采信；以此立论的一方扣分 |

写法：`turn ... --evidence verified`（也认中文「已核/推理/待核/存疑」与 `v/r/t/s`）。
借鉴 `xiaoba-dev/debate` 的 `[verified]/[reasoned]/[to-verify]` 证据标签，加了「存疑」一档
用来收编天道局方士那类「硬圆被拆穿」的发言——「答不上是短处，编派是断处」。

**KO 证据门**：击穿是终局手段，必须落在可核对的证据上。宣布击穿的那一发若没标证据、
或标「存疑/待核」，`check` 默认给出提示，加 `--strict-evidence` 升为硬错误（exit 2）。
这是把「击穿不是打出来的，是立出来的」再收紧一步：光立禁改口铁规还不够，还得有据。

## 七、终局裁决：不只看总分

总分只回答「谁赢了几个回合」，回答不了「这场辩论到底成立没有」。终局要写四层：

1. **比分与胜场**（记账，机械活）。
2. **他们是否在争同一个问题？** 若否，写明各自在争什么，并指出两者为何打不到一起
   （例：一方争名分，一方争位置；名分不承认位置，位置不承认名分）。
3. **共同的失败点。** 双方都没能回答的那件事，往往比胜负更有价值
   （例：两人都「人亡政息」，都没能把「应该」变成「能够」）。
4. **双方都漏掉的第三件事。** 不是「各自漏了什么」，是**两个人一起没看见的那个变量**。
   这一问是整个裁决里最值钱的一问，宁可多花五分钟。

裁决里**不要**写「综合来看 A 略胜一筹」这种和稀泥的句子。要么给结构，要么给判决。

裁决写进账本走 `conclude`，不要手改 `arena.json`：

```
python3 "$SK/scripts/arena.py" conclude --dir ./juban --text-file ./裁决.txt
```

不写就出档，实录里会明写「**裁决**：未填写」，**并且不会按总分替你宣布「本局占胜」**——
工具宁可在纸上留个空，也不替你下一个你没下过的判断。

## 八、一条边界：这套尺不是决策工具

有研究（M3MADBench, 2026）显示**协作式辩论在决策质量上优于对抗式辩论**。
这条结论对本 skill 不构成改设计的理由：论道要的不是「帮你选出最优解」，
是**对抗本身的质量与可看性**。所以这里一律保留对抗内核，只借用它的裁判机制
（盲评、先分项后总评、魔鬼辩手打共识）。

真要做决策，那是另一类活，别拿论道冒充。

还有一条同样要讲在前面：默认两个角色来自**同一个模型**，是两次演绎，不是两个独立智能体。
这不影响好看，但影响结论强度——同一套偏见的两次人格化，分歧比真跨厂商对打要小。
要更强的对抗，把角色换成不同 provider 的 subagent；记账这一侧不用改。

## 九、坏判词样本（照着避免）

| 坏判词 | 病症 |
|---|---|
| 「A 论证充分，逻辑清晰」 | 无原文、无落点 |
| 「B 的回答稍显单薄」 | 没说单薄在哪 |
| 「本回合双方各有千秋，判 A 略优」 | 和稀泥 |
| 「考虑到 A 篇幅更长，信息量更大」 | 冗长偏置，直接违规 |
| 「A 提到的观点很有启发性」 | 裁判在替角色加分，不是判交锋 |
| 「两位都很精彩，这一回合 1:1」 | 收敛警报被当成了判决 |

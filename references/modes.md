# 三种局制

`mode` 只有三个值，别自己发明。选错局制比选错规则集更伤——两方用 roundtable 会散，五方用
duel 会乱。

---

## duel · 一对一（默认）

**什么时候用**：两方立场互斥，用户想看「谁站得住」。

**打法**：一回合一方，攻防交替（A 立论 → B 驳 → A 再驳 → B 再驳…）。每回合只记一条发言，
但分可以同时给双方——因为裁判判的是「这一回合的交锋」，不是「谁说得长」。

**派工**：
```
send_message(A, "第 N 回合，攻守：<你的任务>；对手上一回合原文如下：<全文>")
wait_agent(240000)
```
- 递**全文**，不递摘要。摘要会让对手打空气。
- 每回合要求开场第一句先接住对手的具体某一处，否则判「未交锋」。

**计分**：三分制（见 `judging.md`）。总回合数默认 8。

**注意**：出现严格交替（A 赢 B 赢 A 赢 B 赢）时，先怀疑裁判配平，别急着夸双方旗鼓相当。

---

## roundtable · 圆桌（3–5 方）

**什么时候用**：多方各有立场、没有天然的两极（例：三个学派论「人该怎样活」；五位专家论
「该不该建这座坝」）。

**打法**：两种节奏，选一种并写进 spec：

1. **顺时针一轮**（省事）：第 N 回合，每个角色各发一次 150–250 字，全部收到后由裁判统一判
   「本回合谁最有力」，只给一个人 2 分、其余 0–1 分。
2. **点名互诘**（好看）：每回合由裁判指定「本轮由 X 质询 Y」，X 只提问，Y 只答；其余人不发言，
   但可提交 50 字以内的「旁听按语」，裁判可采纳。

**派工**：同一回合的多条发言**并行**发出去（一次 `send_message` 一个），再逐个 `wait_agent`。
不要串行——串行会让后发言的人读到前面所有人的话，产生锚定，独立判断被抹平。

**计分**：每回合总额仍按 `rounds_total × 3` 分配；若人数 >3，把每回合总额改为 `floor(人数/2)+1`，
并在 spec 的 `scoring` 里如实写。

**坑**：圆桌最容易变成「五个人各说各话然后主持人总结」。破法是**强制质询**：任何一回合，
必须至少有两个人就同一处事实争起来，否则该回合作废重打。

---

## camp · 阵营（团队对团队）

**什么时候用**：用户说的是「两方势力」「两个团队」「三国」「公司两个部门」。

**打法**：每方是一个**小队**（2–3 个角色），队内先议、队外出一人发言。

```
第 N 回合：
  1. 队内会商：给队内每个成员单独 send_message，说明「本轮我方由 X 出使，
     你的任务是给 X 三条弹药，各 60 字内，不许互相同意」。
  2. 出使：只由 X 对本方以外发言 250–500 字，代表全队。X 必须用上队内至少两条弹药。
  3. 裁判判分：记在「队」上，不记在个人上；实录里保留队内会商的痕迹。
```

**计分**：按阵营记。`roles` 里每方的 `id` 仍各自独立（便于记账），但 `spec.camp` 里写
`{"魏": ["A","B"], "蜀": ["C","D"]}`；`render` 会另出一张阵营表。

**可选的「盟约」机制**（三方以上时特别好看）：
- 任何一方可主动提出「盟约」：声明本回合与某一方互不攻击，代价是双方各扣 1 分。
- 背刺：同盟约的回合内攻击盟友，本回合得 3 分但**下一回合全队 0 分**，且裁判在实录里
  明确写出背刺——这是唯一允许压过规则的加分，因为它就是这局的主题。
- 盟约与背刺都要写进 `arena.json` 的 `note`，否则出档看不到，等于没发生。

**坑**：队内会商会被写成互相恭维。在会商的 prompt 里写死「不许同意上一位队友；若没有
不同意见，就给一个反例」。

## 终局有三种，不是一种

`rounds_total` 是**赛程上限**，不是必须打满的配额。一局可以以下面三种方式结束：

| 终局 | 触发 | 记账 | 余下回合 |
|---|---|---|---|
| **打满** | 回合数用完 | 按总分与胜场裁决 | 无 |
| **认输** | 某一方在自报要害上被驳倒，当场认下 | `turn --concede <该角色>`，对手胜 | 不再进行 |
| **击穿** | 裁判判定本回合发言击穿了对方自报的那一句 | `turn --ko <被击穿者>`，发言者胜 | 不再进行 |

三条硬规矩：

1. **认输是一次事件，不是一句客气。** 「你说得有道理」不是认输；认输必须是
   「我那句要害被驳倒了」，且写明被驳在哪一处。含糊的让步只记分，不结局。
2. **击穿必须对得上靶子。** 裁判只能击穿对方**自己报过**的要害。若被判击穿的人全程没报过
   要害，`check` 会提示「打的是稻草人」——那种 KO 该改判，不该出档。
3. **提前终局是合法的，不是截断。** 加了终局之后，`check` 不再要求补齐余下回合；
   但**终局之前**的回合仍必须齐，中间打洞照样报错。

真实比赛就是这样：三回合结束的局，比十回合互相恭维的局值钱。

## 选局一眼表

| 用户的话 | 局制 |
|---|---|
| 「A 和 B 辩一辩」「谁更有资格」 | `duel` |
| 「让几个专家一起论」「圆桌」 | `roundtable` |
| 「两方势力」「两个团队」「三方争天下」 | `camp` |
| 「模拟一场辩论赛」 | `duel` + `persuasion` 规则集 |
| 「让他们吵起来」 | `duel` + `adversarial` |

---

## 多人局的硬性成本提醒

`duel` 一场 8 回合 ≈ 16 次 agent 往返；`roundtable` 五方 5 回合 ≈ 25 次；`camp` 两营各三人
8 回合 ≈ 70 次以上。超过 40 次往返的局，**先跟用户说一句「这局要跑半小时以上」再开**，
不要闷头跑完再解释为什么慢。
